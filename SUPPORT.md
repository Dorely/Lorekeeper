# Support

Lorekeeper is maintained on a best-effort basis. Use
[GitHub issues](https://github.com/Dorely/Lorekeeper/issues) for reproducible bugs,
installation problems, and focused questions. Check existing issues first and
include the version, operating system, install channel, and reproduction steps.

Use a small synthetic project when an example is needed. Do not upload your
database, private manuscripts, provider credentials, OAuth tokens, raw
diagnostic logs, or private GitHub remote details. Review any excerpt before
sharing it. Security concerns use [SECURITY.md](SECURITY.md).

The app is free to install. AI, search, embedding, and image providers require
your own account or credentials and may charge independently. The maintainer
cannot resolve a provider's billing or account access issue.

If you want to support development, you can
[buy Dorely a coffee](https://buymeacoffee.com/dorely). Donations are optional and
do not change the license or create a paid support commitment.
