# Bundled PicturePage fonts

All bundled families were sourced from the Google Fonts repository at commit
`ec0464b978de222073645d6d3366f3fdf03376d8`. Each family directory contains
the upstream `OFL.txt` license.

Static upstream files were copied unchanged for Atkinson Hyperlegible, Andika,
Balsamiq Sans, Patrick Hand, and Kalam. Google Fonts publishes the selected
Lexend, Nunito, Lora, Merriweather, Fredoka, and Roboto Mono revisions as
variable sources; the checked-in 400 and 700 TTF files are static instances
created with fontTools 4.63.0. Width, optical-size, and other non-weight axes
were fixed at their upstream defaults.

Source directories:

- `ofl/atkinsonhyperlegible`
- `ofl/andika`
- `ofl/lexend`
- `ofl/nunito`
- `ofl/lora`
- `ofl/merriweather`
- `ofl/fredoka`
- `ofl/balsamiqsans`
- `ofl/patrickhand`
- `ofl/kalam`
- `ofl/robotomono`
