current implementation; the routed architecture chapters and the source are.

## Evidence policy

A brief distinguishes evidence traceable to a cited source, Lorekeeper's
interpretation of it, implementation decisions, and platform limitations.
Publishing vendors, standards, dependency features, and licenses change; recheck
the relevant primary sources at the start of every publishing feature. A
research recommendation is not a dependency approval or conformance claim.

Delete a brief once it no longer describes the current product. Git history
keeps the retired research.
