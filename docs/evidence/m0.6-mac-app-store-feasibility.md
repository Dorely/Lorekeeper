# M0.6 Mac App Store feasibility prerequisite record

Status: **Blocked; no MAS implementation or device execution**

Date: 2026-09-16

M0.6 cannot begin until the owner supplies all of the following and selects the
signed build host:

- Apple Developer Team ID.
- MAS development certificate and provisioning profile.
- Test App ID.
- Apple-silicon test Mac.

The current repository has no `mas-dev` build flavor, MAS Electron runtime,
entitlement files, Apple credentials, signing configuration, MAS artifact, or
Mac App Store workflow. The existing direct-DMG path and dispatch-only macOS
release workflow remain unchanged. Cloud-only access is not a substitute for the
selected signed Apple-silicon device.

When unblocked, the acceptance implementation must use Electron’s MAS runtime,
not the normal macOS Electron build, and give the application and every helper
separate entitlement files. The starting profile is limited to App Sandbox,
loopback/network client and server access, user-selected read/write files, and
printing. It contains no embedded credential, broad filesystem entitlement, App
Group, or library-validation exception. Add an entitlement only when a specific
signed-device failure demonstrates its necessity.

The signed-device evidence must cover signing and effective entitlements; the
Electron/.NET/Press process tree; the loopback host; sandboxed SQLite/history
locations; import/export picker access; application print preview and its native
handoff; and Store updater suppression. OAuth and external services need separate
safe-test-account authorization. If Press, .NET, SQLite, printing, or file access
does not work under this minimum profile, stop the Store channel and record the
blocker rather than weakening the sandbox speculatively.

Do not upload to App Store Connect, notarize, publish, add GitHub signing secrets,
or modify the existing dispatch-only macOS workflow without new explicit owner
authorization. The governing platform references are
[Electron’s Mac App Store guide](https://www.electronjs.org/docs/latest/tutorial/mac-app-store-submission-guide)
and [Apple’s App Sandbox guidance](https://developer.apple.com/documentation/security/protecting-user-data-with-app-sandbox).
